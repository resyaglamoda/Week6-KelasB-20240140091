# Tugas PAW Week 6 — Tema Cafe (Kopi & Ruang)

Project ini terdiri dari dua halaman utama:
1. **Etalase (`public/index.html`)**: Katalog menu yang datanya diambil dari DummyJSON API. Dilengkapi fitur pencarian nama menu, filter kategori, dan badge "Stok Menipis" untuk stok di bawah 10.
2. **Caption (`public/form.html`)**: Generator caption media sosial untuk promosi menu. Dilengkapi validasi realtime dan format otomatis Rupiah serta hashtag.

## Cara Menjalankan
Disarankan menggunakan ekstensi **Live Server** di VS Code. Buka `public/index.html` menggunakan Live Server agar fungsi Fetch API berjalan tanpa terblokir kebijakan CORS browser.

## Struktur Folder
- `public/` : Berisi file HTML, CSS, dan JS utama.
- `latihan/` : Berisi script uji coba fetch dan test logika dasar.
